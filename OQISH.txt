---------------------------------------------------------------------------
 • Karkas zavod LIMS'i bilan bir xil: chapda yon panel (Umumiy ko'rinish +
   har bir laboratoriya, rangli holat nuqtasi bilan; yig'ish mumkin), tepada
   sahifa yo'li, jonli soat, til menyusi, mavzu, kirish/foydalanuvchi.
   Kontent butun ekran kengligini egallaydi.
 • Ranglar, shrift (Inter), panellar, tugmalar — LIMS'dagi kabi. Sukut mavzu — yorug'.
 • Umumiy ko'rinish: 6 ta KPI (+ onlayn laboratoriyalar), 30 kunlik dinamika,
   reyting va uskunalar tayyorligi, barcha laboratoriyalar bo'yicha «Ish oqimi»,
   laboratoriyalar JADVALI (holat, bugungi sonlar, 30 kun, mediana, uskunalar,
   dinamika, oxirgi aloqa). Kichik ekranda jadval o'rniga kartalar.
 • Laboratoriya sahifasi — LIMS «Rahbariyat paneli» tuzilishida: KPI, ish oqimi
   (yoshi bo'yicha), dinamika + smenalar jadvali, guruhlar/bo'limlar, uskunalar,
   buyurtmalar, ishchi varaqlar.
 • Tuzatildi: sana «M11 26, Thu» → «pay, 26-noyabr»; «+2591%» kabi foizlar —
   endi o'tgan davr juda kichik bo'lsa «solishtirib bo'lmaydi», 2 baravardan
   ko'p bo'lsa «×27» ko'rinishida (sichqonchani olib borsa — o'tgan davr soni).

1. LOKAL KOMPYUTERDA (lims-ngmk)
---------------------------------------------------------------------------
  1) Zip ichidagi fayllarni loyiha ildiziga yoying (ustiga yozish — «Ha»).
     OQISH.txt ni loyihaga qo'shmang.
  2) Endi kerak bo'lmagan 2 faylni o'chiring:
       git rm resources/js/Components/TopBar.vue resources/js/Components/SiteFooter.vue
  3) npm run build
  4) php artisan serve → brauzerda Ctrl+F5 bilan tekshiring.
  5) git add -A
     git add -f public/build
     git commit -m "Portal v3: LIMS uslubidagi dizayn"
     git push
